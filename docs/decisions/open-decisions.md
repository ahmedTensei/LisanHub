# القرارات المفتوحة

قاعدة العمل: لا يُحسم أي بند هنا بالاستنتاج. عند الحاجة إليه، يُعرض على أحمد مع الخيارات.
بلد المرجع: الجزائر. المراحل: أ (منصّة مجانية متكاملة)، ب (تقييمات المستخدمين والتحسين)، ج (القانون والاشتراكات والمدفوعات) — انظر `docs/mvp-roadmap.md`.
