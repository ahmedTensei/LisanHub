# LisanHub — دليل البدء السريع (لأحمد)

> الواجهة العلنية للمشروع في `README.md`. هذا الملف هو خطوات التشغيل على حاسوبك.

منصّة تعلّم لغات مجتمعية: يصنع المجتمع المحتوى ويراجعه ويطوّره، وكل مورد تعليمي مرتبط بزوج لغوي (لغة أم ← لغة هدف).

## البدء

طريقتان، والنتيجة واحدة:

1. **Claude Code (موصى بها):** افتح هذا المجلد في Claude Code واكتب «ابدأ». يتولّى التثبيت والتحقّق وتفعيل المهارات حسب `CLAUDE.md`، ويصلح أي خطأ يظهر.
2. **نقرة مزدوجة:** شغّل `start-windows.cmd`. يثبّت الحزم، ويفعّل المهارات، ويشغّل الفحص الكامل، ثم يفتح التطبيق على http://localhost:3000.

الأوامر الأساسية:

| الأمر | ما يفعله |
| --- | --- |
| `npm run dev` | تشغيل التطبيق على http://localhost:3000 |
| `npm run check` | الفحص الكامل: lint + الأنواع + الاختبارات |
| `npm run build` | بناء نسخة الإنتاج |
| `npm run setup` | تثبيت المهارات في `.claude/skills` وإعدادات CI وVS Code |

## محتويات المجلد

- `CLAUDE.md` — تعليمات المشروع لـ Claude Code.
- `start-windows.cmd` — تجهيز المشروع وتشغيله على Windows بنقرة مزدوجة.
- `claude-skills/` — مهارات المشروع الـ17 (v2.1 + مهارة الإضافات).
- `setup/` — مصادر إعدادات GitHub Actions وVS Code (تُثبَّت بـ `npm run setup`).
- `docs/specification/` — وثيقة المواصفات الكاملة (docx + Markdown).
- `docs/mvp-roadmap.md` — خارطة بناء النسخة الأولى.
- `docs/decisions/` — القرارات المحسومة والمفتوحة.
- `docs/adr/` — قرارات البنية التقنية.
- `docs/analysis/` — تحليل تحديثات الوثيقة والمهارات.
- `src/` — التطبيق (Next.js) ووحدات المجال.
- `supabase/` — قاعدة البيانات: الجداول وسياسات الأمان واللغات.
- `tests/db/` — اختبارات قواعد قاعدة البيانات.
