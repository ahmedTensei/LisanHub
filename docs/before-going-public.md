## 4. قبل أول مستخدم حقيقي (خارج نطاق المستودع)

- سياسة خصوصية مختصرة وموافقة صريحة عند التسجيل (القرار المفتوح **ق12**، القانون 18-07 المعدَّل بـ 25-11).
- ترخيص المحتوى الذي ينشئه الأعضاء (**ق7**)؛ `README.md` يقول صراحةً إنه لم يُحسم بعد.
- إبقاء `README.md` صادقًا (القرار **ح8**): سطر الحالة وعدد الاختبارات (123 الآن) يُحدَّثان مع كل تغيير حقيقي، ولا أرقام مخترعة.

## 5. عند تحويل المستودع إلى عام

1. تفعيل **Secret scanning + Push protection** (مجاني للمستودعات العامة؛ رُفض الآن لأنه خاصّ): `gh api -X PATCH repos/ahmedTensei/LisanHub -f "security_and_analysis[secret_scanning][status]=enabled" -f "security_and_analysis[secret_scanning_push_protection][status]=enabled"`
2. **حماية الفرع `main`** (تمنع المسح وإعادة كتابة التاريخ): الأمر في `docs/prompts/GIT-initial-push.md` §7.
3. تفعيل **Private vulnerability reporting** (إعدادات المستودع → Security).
4. إعادة تشغيل فحص القائمة أعلاه (§1) على آخر شجرة: `git grep -n -iE "C:\\\\Users|@gmail|\+213" HEAD` يجب أن يعود فارغًا.
5. `docs/specification/` تبقى مستثناة (`.gitignore`) — لا تُنشر بقرار أحمد.

## 6. ما لا يُضاف أبدًا إلى المستودع

مفتاح `service_role` أو أي مفتاح سرّي، `.env.local` وكل `.env*` عدا `.env.example`، `supabase/.temp` (يحوي معرّف المشروع وعنوان المجمّع)، `.claude/` المولَّد، المواصفات ونموذج العمل.
