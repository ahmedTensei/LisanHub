# Contributing

Thank you for looking. Please read this before opening anything.

## Code contributions are closed for now

Pull requests will not be merged while the architecture is still moving and the licence position is being settled. This is temporary, and it is not a judgement on anyone's work — it avoids asking people to spend effort on code that may be restructured next week, and it keeps the copyright position simple for a project that is licensed noncommercially.

If that changes, this file changes with it.

## What is welcome

- **Bug reports** and **ideas** through GitHub Issues. Say what you expected, what happened, and how to reproduce it.
- **Security reports** — do not open an Issue. Follow [SECURITY.md](SECURITY.md).
- **Language and translation feedback** on the interface strings in `messages/`: an Issue is the right place.

## Where community participation actually happens

LisanHub is built so that the community contributes **inside the platform**: creating lessons and exercises, reviewing them, translating them into other language pairs, reporting mistakes and outdated expressions. That is the real contribution path, and it opens when the platform does.

## Licence of contributions

This project is licensed under the [PolyForm Noncommercial License 1.0.0](LICENSE), and the copyright holder intends to operate a commercial service based on it in the future. Because of that, any future code contribution will require a contributor licence agreement. Until that is in place, please do not send code.

## Running it locally

The repository is public so the work can be read and audited. It needs a Supabase project of your own; see `docs/SETUP.md` and `docs/quickstart-ar.md`. There is no public instance and no shared database.
